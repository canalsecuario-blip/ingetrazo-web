Política de assinatura de código

Como os programas do IngeTrazo para Windows são assinados e quem responde por eles.

Assinatura de código gratuita fornecida pela SignPath.io, certificado da SignPath Foundation.

Situação: a assinatura com a SignPath está sendo configurada. Até lá, os programas para Windows são publicados sem assinatura; esta página descreve como serão assinados e será atualizada quando a assinatura começar.

O que é assinado

  • Os executáveis do IngeTrazo para Windows, ingetrazo.exe e ingetrazo-mcp.exe, e o instalador ingetrazo-setup-<versão>.exe.
  • Só é assinado o que é compilado a partir do código-fonte público deste projeto. Os componentes de terceiros incluídos no pacote (Python, Qt/PySide6 e outras bibliotecas livres) não são assinados com o nosso certificado.
  • Cada versão é compilada no GitHub Actions, a partir do repositório público, pelo fluxo de trabalho "Build Windows"; nada do que é publicado é compilado no computador de alguém. Os downloads estão nas versões publicadas no GitHub.

Funções da equipe

  • Autores e revisores: o código é escrito pelo responsável do projeto e pelos colaboradores. Toda mudança de um colaborador entra por um pull request público que o responsável revisa antes de aceitar.
  • Aprovadores: Marco Sumari Tellez (@tuxiasumari), responsável do projeto. Cada assinatura de uma versão é aprovada manualmente.
  • As contas com acesso ao repositório e à assinatura usam autenticação em dois fatores.

Privacidade

Este programa não transfere nenhuma informação para outros sistemas em rede, a menos que isso seja solicitado expressamente pelo usuário ou pela pessoa que o instala ou utiliza. Não tem telemetria nem procura atualizações por conta própria. Só se conecta quando você usa uma função que precisa disso:

  • Mapas e relevo do terreno (OpenStreetMap, Esri, EOX, Sentinel-2, modelos de elevação do AWS Open Data) e a busca de lugares (Nominatim).
  • O botão "Localizar-me", que estima a sua cidade pelo seu endereço IP (ipapi.co).
  • A biblioteca de componentes (ingetrazo.com) e as de materiais e modelos (Poly Haven, ambientCG, Sketchfab).
  • O assistente de IA, que só se comunica com o provedor que você escolher e configurar com a sua própria chave (ou com um modelo local, como o Ollama).

Como verificar um arquivo

  • No Windows: clique com o botão direito no .exe ▸ Propriedades ▸ aba Assinaturas Digitais.
  • Se um antivírus marcar um arquivo do IngeTrazo, avise-nos no GitHub ou por e-mail.
