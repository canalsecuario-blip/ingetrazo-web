Política de firma de código

Cómo se firman los programas de IngeTrazo para Windows y quién responde por ellos.

Firma de código gratuita proporcionada por SignPath.io, certificado de SignPath Foundation.

Estado: la firma con SignPath está en proceso de alta. Hasta que se complete, los programas para Windows se publican sin firmar; esta página dice cómo se firmarán y se actualizará cuando empiece.

Qué se firma

  • Los ejecutables de IngeTrazo para Windows: ingetrazo.exe y ingetrazo-mcp.exe, y el instalador ingetrazo-setup-<versión>.exe.
  • Solo se firma lo que se compila a partir del código fuente público de este proyecto. Los componentes de terceros que van dentro del paquete (Python, Qt/PySide6 y otras bibliotecas libres) no se firman con nuestro certificado.
  • Cada versión se compila en GitHub Actions, a partir del repositorio público, con el flujo de trabajo «Build Windows»; nadie compila en su propio equipo lo que se publica. Las descargas están en las versiones publicadas en GitHub.

Roles del equipo

  • Autores y revisores: el código lo escriben el responsable del proyecto y los colaboradores. Todo cambio de un colaborador entra por un pull request público que el responsable revisa antes de aceptarlo.
  • Aprobadores: Marco Sumari Tellez (@tuxiasumari), responsable del proyecto. Cada firma de una versión se aprueba a mano.
  • Las cuentas con acceso al repositorio y a la firma usan autenticación en dos pasos.

Privacidad

Este programa no transfiere ninguna información a otros sistemas en red a menos que lo pida expresamente el usuario o la persona que lo instala o lo usa. No tiene telemetría ni busca actualizaciones por su cuenta. Solo se conecta cuando usas una función que lo necesita:

  • Mapas y relieve del terreno (OpenStreetMap, Esri, EOX, Sentinel-2, modelos de elevación de AWS Open Data) y la búsqueda de lugares (Nominatim).
  • El botón «Ubicarme», que estima tu ciudad por tu dirección IP (ipapi.co).
  • La biblioteca de componentes (ingetrazo.com) y de materiales y modelos (Poly Haven, ambientCG, Sketchfab).
  • El asistente de IA, que solo habla con el proveedor que tú elijas y configures con tu propia clave (o con un modelo local, como Ollama).

Cómo comprobar un archivo

  • En Windows: clic derecho sobre el .exe ▸ Propiedades ▸ pestaña Firmas digitales.
  • Si un antivirus marca un archivo de IngeTrazo, avísanos en GitHub o por correo.
